## 1. 一句话世界观

十八年前，一场被定为天灾的「封雾夜」掩盖了官、商、门派共同参与的人祸试验；十八年后，一名行路侠客在雾津驿卷入伪匪灭口案，由地方血案追到沉钟院旧场，迫使江湖回答：缄默换来的太平，还值不值得用活人的嘴去续。

## 2. 作品定位与核心命题

- **类型**：低奇幻、重人情、带悬疑调查的单人武侠 RPG。
- **玩家身份**：行路人，非天命救世主；**不是**来办户籍的人。
- **表层目标**：查灭口、护送证人、追封雾夜真相、对抗持续灭证。
- **深层目标**：真相应如何公开、由谁承担代价；规矩是否允许揭师门与官署之丑。
- **核心命题**：侠，不只是替人报仇，更是在人人都想让证人闭嘴时，把人护到能把话说完的地方，并承担说完之后的代价。
- **情绪基调**：清冷、克制、人间烟火；悲剧来自护短与灭口。

## 3. 从参考主线到本作的改编方法

| 参考结构的叙事功能 | 《雾州侠行》的原创转译 |
|---|---|
| 新手村以小见大 | 雾津驿伪匪灭口；专取旧案抄本与证人线索，而非劫财 |
| 地方帮派与连续奇案 | 岭上「匪」盖住灰烟寨余部与假冒灭口者 |
| 信物推动跨区追踪 | 十三名立场冲突的活人证人 + 可交叉印证的物证与响痕 |
| 门派旧怨 | 五门参与试验与事后缄默；后辈与旧人分裂 |
| 神秘邪派 | **同尘阁**：灭证与统一口径的秘密组织（非单一魔教） |
| 绝世秘藏 | 《沉钟录》是决策与伤亡档案，不是神功 |
| 武林大会 | 「万证会」：公审式江湖汇合 |
| 主线后扩展 | 真相出口后各地旧怨浮现 |

## 4. 世界规则（摘要）

### 4.1 雾与响痕

息砂矿尘 + 钟鸣可在金石上留**片段响痕**。规则：不完整、会被执念扭曲、大钟危险、主角因幼年现场经历更敏感。禁止一次回放破案。

### 4.2 武学

套路 / 内功 / 轻功；绝招靠聚气。门派运气可作响痕「技术指纹」。

### 4.3 缄默规矩（替代「失名秩序」）

封雾夜后的三不暗约：**不究、不录、不问**。违者遭栽赃、除名门墙、断路、灭口——传统江湖与官场手段，**不是**全民删籍魔法。

刀让人闭嘴；伪证与统一口径让刀看起来正当。

## 6. 地理（V1）

轻功：一处必经基础跳 + 两处可选高级跳 + 一处可选踏水（不锁主线）。

## 15. 首章落地结论（v0.2）

V1 讲清四件事：

1. 天灾说法与现场对不上。  
2. 现在仍有人为旧案灭口。  
3. 主角与当晚有关，但身世未完。  
4. 真相是活人与物证，不是一件可抢的宝物。  

玩家应想继续知道：**谁在统一口径、谁还在杀人灭证。**
