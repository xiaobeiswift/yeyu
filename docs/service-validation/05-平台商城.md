## 前置与步骤

- 沙盒商品、零真实金额测试方式、订单日志和补单/查询权限。
1. 覆盖正常购买、用户取消、支付失败、重复点击、重复回调和回调乱序。
2. 在付款后回调前退出/断线，重进后按订单或权益游标补单。
3. 注入成功响应丢失和迟到回调；同 idempotency key 必须返回原结果，不重复发货。
4. 验证商品下架、数量边界、账号切换、普通商品 owned count 与抽卡凭证不混用。

## 通过与降级

- 订单身份稳定、结果可查询且补单不重发，才可标记 `AVAILABLE`。
- 只能人工补单则标记 `LIMITED`，正式入口仍关闭。
- 无可靠补单/查询时标记 `UNAVAILABLE`，隐藏所有付费功能。
