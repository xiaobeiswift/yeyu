# Y3 原生服务验证索引

这里记录真实 Y3 平台能力的证据，不记录推测。纯 Lua Fake 通过只能证明应用契约可测试，不能把服务状态从 `UNVERIFIED` 改为 `AVAILABLE`。

## 状态词

- `UNVERIFIED`：缺少真实环境证据，功能开关必须关闭。
- `AVAILABLE`：全部必测项有构建号、账号、时间和日志证据。
- `LIMITED`：仅部分能力可用，报告必须写明降级边界。
- `UNAVAILABLE`：已复现平台不满足契约，使用既定降级方案。
