# 云存档验证记录

**当前状态：UNVERIFIED。** `cloud_save=false`，启动壳使用 `PLATFORM_UNAVAILABLE` 安全实现。

## 前置

- 已发布测试地图、两个隔离测试账号、槽 1–5 与公开槽权限。
- 能查看平台请求结果和频控日志；准备接近容量上限的三层 DTO。

## 必测步骤

1. 对每个槽执行空值、最小值、正常值和容量边界的写入—上传—退出—重进—下载—校验。
2. 注入下载失败，确认进入只读重试且不创建新档、不写任何槽。
3. 注入单槽写失败、响应丢失、陈旧 revision 与双会话冲突；按目标 revision/checksum 查询，不换幂等键盲重写。
4. 槽 2–5 成功、槽 1 Manifest 失败时，确认旧 Manifest 仍是提交边界并可前向恢复。
5. 验证三层嵌套、整数范围、容量、频控、回读延迟和退出前保存行为。

## 通过与降级

- 全部回读一致且失败不会覆盖有效云档，才可标记 `AVAILABLE`。
- 条件写或回读能力受限则标记 `LIMITED`，进入冲突/只读策略。
- 无法区分下载失败与空档时标记 `UNAVAILABLE`，禁止云档写入和正式发布。
