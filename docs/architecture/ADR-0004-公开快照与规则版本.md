# ADR-0004：公开擂台快照、来源向量与规则版本

> 状态：已采纳（规划阶段）

## 决策

公开快照是派生且不可信的数据，不能成为私人构筑的第二权威。

### SourceRevisionVector

至少包含：槽 3 的角色/阵型/武学/经脉修订、槽 4 的装备实例/Loadout 修订、平台权益对账游标、`content_version`、`rules_version`、快照 Schema 版本。任一来源变化把公开快照标记 DIRTY。

### ArenaRuleBundle

挑战绑定一个不可变规则包：`arena_rules_id`、`rules_version`、`content_version`、允许的快照版本、迁移器版本、计分版本和 seed 派生版本。双方必须已经是同一兼容版本，或先经纯函数迁移、重校验和重哈希；否则拒绝挑战且不计分。

### 快照校验

- 只接收各 owner 提供的公共 DTO 子集，不自创属性字段。
- 忽略并报告最终攻击、防御等派生属性，全部本地重算。
- 校验白名单 ID、范围、数量、阵位、权益计数和来源哈希。
- seed 从规范化字节哈希映射到 `1..2147483646`；余数 0 映射为 1，算法版本写入规则包。

### 挑战意图

排位开战前保存挑战 intent：双方快照哈希、排名、周期、赛季、seed 和计分上下文。重进后确定性续算/重放并结算；若规则明确无法恢复，按已冻结的强退策略处理，不能通过退出规避失败扣分。
