# 新手引导与设置系统工程规格

> 状态：待评审
>
> 遵循：[通用工程约定](./00-通用工程约定.md)

## 1. 目标与非目标

本系统负责按玩家进度教授移动、轻功选点跳跃、踏水通行、交互、战斗、聚气绝招、自动模式、装备、武学、编队换位、制作和传送，并且是画面、声音、输入绑定、战斗速度、可访问性和提示偏好的唯一领域所有者。19 只负责 UI/输入表现和调用本文用例。

目标：引导可配置、可跳过、可重看、可恢复；不因 UI 关闭或存档重进卡死主线；设置修改即时预览且安全持久化；键鼠和 UI 均有完整路径。

非目标：不在引导脚本中直接发任务奖励、改任务状态或操纵战斗结果；不使用引导绕过系统前置；不实现账号级平台设置同步之外的外部服务。

## 2. 依赖

依赖 UI/输入、任务、世界交互、战斗、背包、装备、武学、阵型、制作、26 轻功探索与特殊通行、SaveCoordinator/SectionOwnerRegistry 和 Y3 表现。通过应用事件观察事实，通过正式用例执行玩家操作。

## 4. 引导领域模型

### TutorialDefinition

| 字段 | 类型 | 说明 |
|---|---|---|
| `tutorial_id` | StableId | 永久稳定 |
| `category` | enum | `movement/combat/growth/system` |
| `priority` | integer | 同时满足时的顺序 |
| `trigger_condition` | 条件表达式 | 只读领域事实 |
| `prerequisite_ids` | ID 列表 | 必须完成或跳过 |
| `steps` | Step 列表 | 有序步骤 |
| `skippable` | boolean | 关键安全提示可不可跳过 |
| `replayable` | boolean | 是否进入帮助页 |
| `blocking_policy` | enum | `none/input_scope/modal` |
| `completion_condition` | 条件 | 不依赖纯点击“下一步”时使用 |
| `version` | integer | 行为变更时提升 |

### TutorialStep

| 字段 | 类型 | 说明 |
|---|---|---|
| `step_id` | string | 教程内唯一 |
| `presentation` | enum | 气泡、遮罩、高亮、演示图、短视频占位 |
| `message_key` | string | 本地化文本 |
| `target_anchor` | string? | 语义 UI 锚点，不直接存节点句柄 |
| `allowed_actions` | 动作列表 | input_scope 时白名单 |
| `advance_on` | 事件/确认 | 明确完成条件 |
| `fallback` | enum | 锚点不存在时跳过、转文本或延迟 |

### TutorialProgress

字段：`tutorial_id`、`definition_version`、`state`（`unseen/queued/active/completed/skipped`）、`current_step_id`、`seen_count`、`last_context`。重看不回退正式进度，使用独立 replay session。

## 5. 引导调度规则

1. 应用事件进入调度器，只标记候选，不立即抢占当前模态流程。
2. 过滤已完成/跳过、前置不满足和当前场景不允许的候选。
3. 按 priority、首次触发序列、tutorial_id 稳定排序。
4. 战斗结算、存档恢复、剧情强演出期间只排队，不弹出。
5. 当前引导完成/跳过后再评估队列。

同一事件重复到达不得重复排队。教程中断（切地图、断线、UI 重建）后，从可恢复步骤继续；若目标锚点永久不存在，执行 fallback 并记录诊断，不能锁死输入。

## 6. 首章引导序列

| 顺序 | 教学 | 完成事实 |
|---:|---|---|
| 1 | 点击移动与 WASD | 玩家到达目标区 |
| 2 | 打开轻功选点、识别有效/无效格、移动光标、确认或取消 | 一次合法 `TraversalLanded`；取消分步只要求返回普通探索态 |
| 3 | 装备已取得的踏水轻功并进入/离开水面 | 同一教学区产生合法 `WaterWalkEntered` 与 `WaterWalkExited` |
| 4 | NPC 交互与对话选择 | 指定对话完成 |
| 5 | 普通攻击与行动顺序 | 首场教学战达到指定事件 |
| 6 | 聚气绝招 | 玩家成功释放一次绝招 |
| 7 | 自动/手动切换 | 模式切换完成，不要求保持 |
| 8 | 装备与武学 | 合法装备/装配用例成功 |
| 9 | 四人编队与换位 | FormationChanged 成功 |
| 10 | 背包、制作与商店 | 至少完成一个教学配方 |
| 11 | 马车传送 | 合法传送完成 |

教学战可以临时保证聚气条件，但必须通过 Encounter 教学配置实现，不得让引导直接写战斗资源。

轻功与踏水教学均可跳过并可从帮助页重看。跳过、重看或点击“我已了解”只改变 TutorialProgress：不得授予 LightnessTraversalProfile、添加能力标签、创建 TraversalSession、改变可达格、瞬移角色或伪造 `TraversalLanded`、`WaterWalkEntered`、`WaterWalkExited`。首章必经能力必须由 04/26 认可的正常剧情或武学获得流程在教学之前保证授予；玩家提前完成对应事实时可直接完成教学。

首次跳跃教程内部步骤固定为：提示 `OpenLightnessTargeting` → 说明地面 TraversalCell 范围且强调不是战斗 3×3 阵位 → 指认陆地有效、水面有效、无效及其纹样/图标 → 用鼠标或键盘 `MoveLightnessCursor` 悬停目标并预览路线/落点 → `ConfirmLightnessTarget` 后等待权威 `TraversalLanded` → 在安全位置再次打开并用 `CancelLightnessTargeting` 退出。确认前若六项 `ReachabilitySourceVector` 任一改变，教程只解释系统重校验并刷新候选，不替玩家自动确认。

## 7. 设置模型

### SettingsProfile

| 分类 | 字段 | 范围/默认 |
|---|---|---|
| 画面 | 画质、特效密度、阴影、帧率档、镜头震动、轻功轨迹/水花密度 | 设备探测默认，值域白名单；不改变可达格 |
| 声音 | 主音量、音乐、音效、语音 | 0–100 整数 |
| 战斗 | 默认自动、表现速度、伤害数字、镜头特写 | 不改变权威规则 |
| 操作 | 点击移动、WASD、镜头拖动、按键绑定、轻功选点打开/光标移动/确认/取消 | 冲突校验 |
| 可访问性 | UI 缩放、色弱方案、字幕、闪烁降低、轻功有效/无效格高对比纹理 | 默认安全值；颜色不是唯一状态编码 |
| 提示 | 教程提示、二次确认、拾取摘要 | 分类开关 |
| 隐私/诊断 | 可选诊断日志级别 | 不包含敏感信息 |

设置分为设备本地偏好与玩家云偏好。画质、帧率档、阴影、特效密度等设备性能设置只写设备本地存储；教程进度、战斗默认模式、声音、提示和可访问性云偏好按本文槽位保存。若平台不支持可靠设备本地存储，设备字段每台设备使用安全默认并允许本局修改，不得降级写入云槽覆盖其他设备。

## 8. 输入绑定规则

- 每个动作有稳定 `action_id`，UI 显示绑定而不是硬编码按键文字。
- 保留键（系统退出等）不可重绑；同上下文冲突必须阻止保存或显式交换。
- 点击移动与 WASD 可以同时启用；文本输入时屏蔽游戏动作。
- 轻功输入使用稳定 action_id：`OpenLightnessTargeting`、`MoveLightnessCursor`、`ConfirmLightnessTarget`、`CancelLightnessTargeting`；键盘、鼠标和 UI 按钮最终提交同一 26 用例，绑定只改变输入映射。
- 引导限制输入时只限制当前声明动作域，紧急关闭、设置和辅助功能保持可用。
- 恢复默认必须二次确认并可撤销到本次打开设置页前的快照。

## 9. 应用用例

| 用例 | 输入 | 核心事务 | 错误/幂等 |
|---|---|---|---|
| `EvaluateTutorials` | 领域事件、上下文 | 计算候选并排队 | 同 event_id 去重 |
| `AdvanceTutorial` | 教程/步骤/触发事实 | 校验 advance_on 后推进 | 非当前步骤拒绝 |
| `SkipTutorial` | 教程 ID | 标记 skipped，解除输入限制 | 重复跳过返回当前状态 |
| `ReplayTutorial` | 教程 ID | 建临时重看会话 | 不改 completed/skipped |
| `PreviewSettings` | 设置差异 | 临时应用表现 | 关闭页面可回滚 |
| `CommitSettings` | 完整合法 Profile、幂等键 | 校验、应用，并向 SaveCoordinator 提交 settings_profile section 变更 | 冲突/不支持值返回错误 |
| `ResetSettings` | 分类/全部 | 生成默认并预览 | 提交前不持久化 |

## 10. 事件

消费的权威事件必须使用 EventSchemaRegistry 中生产者定义的原名：

- `QuestAccepted`、`DialogueCompleted`、`EquipmentEquipped`、`FormationChanged`、`CraftCompleted`、`TravelCompleted`。
- 轻功教学只消费 26 注册的权威事实 `TraversalLanded`、`WaterWalkEntered`、`WaterWalkExited`；候选高亮、打开选点、光标移动和动画结束不能独立完成教学。
- 战斗教学按具体 CombatEvent 消费 `ActionFinished`、`MoveUsed`、`CombatModeChanged` 和必要的 `CombatFinished`；不存在 CombatEventObserved 这一领域事件。

发布：`TutorialQueued`、`TutorialStepAdvanced`、`TutorialCompleted`、`TutorialSkipped`、`SettingsChanged`、`InputBindingsChanged`。教程展示事件不驱动奖励。

| event_type | 关键 payload |
|---|---|
| `TutorialQueued` | tutorial_id、definition_version、trigger_event_id |
| `TutorialStepAdvanced` | tutorial_id、from_step_id、to_step_id、trigger_event_id |
| `TutorialCompleted` / `TutorialSkipped` | tutorial_id、definition_version、reason、receipt_id |
| `SettingsChanged` | changed_setting_ids、profile_revision、scope（PLAYER_CLOUD/DEVICE_LOCAL） |
| `InputBindingsChanged` | changed_action_ids、profile_revision |

UIAnchorAvailable 是 19 的 presentation 内部信号，不进入 DomainEvent/EventSchemaRegistry。引导通过 UIAnchorQuery 查询锚点；锚点缺失时执行 fallback，不能用内部信号独立推进领域步骤。

## 11. 存档 DTO

槽 `5` 的 `tutorial_progress` section（本文唯一 owner）：`tutorial_progress_by_id` 扁平表、已确认提示集合、教程 Schema 版本。为满足三层限制，步骤状态不保存嵌套历史，只保存当前 step 和最终 state。

槽 `1` 的 `settings_profile` section（本文唯一 owner）：保存玩家云偏好设置版本、战斗默认模式、声音、提示、可访问性和玩家级输入方案。19 不保存第二份设置 DTO，也不注册对应 SectionOwner。

设备本地存储：画质、帧率档、阴影、特效密度、分辨率相关缩放与设备能力快照。设备字段不进入槽 1 或槽 5；无本地存储能力时使用安全默认，不做云端替代写入。

本文不拥有槽 1 或槽 5 整槽。教程与云偏好只能提交各自 section 变更，由 SaveCoordinator 合并并按 18 的 checkpoint 协议保存；不得读取整槽后覆盖其他系统 section。设备本地偏好不进入云端 SectionOwnerRegistry。

迁移：新增教程默认为 unseen；教程版本改变时，已完成玩家保持完成，除非属于必须重新确认的安全/合规提示；删除教程保留墓碑避免旧队列复活。

## 12. Y3 与 UI 适配

- 通过语义锚点注册表查找 UI，不保存节点句柄。
- 遮罩、高亮和输入拦截由本地表现层执行；推进命令回到同步应用层。
- 设置适配器映射 Y3 音量、镜头、特效和输入 API；不支持字段应标记 disabled 并解释原因。
- UI 覆盖正常、高亮目标缺失、排队、跳过确认、重看和只读存档状态。
- 轻功教学通过 19 的 UIAnchorQuery 定位选点提示、有效/无效格图例、确认与取消动作；覆盖层本身只呈现 26 的候选集。
- 教程不得请求或展示 26 已按 reveal policy 隐藏的 TraversalCell；未探索出口、隐藏落点和任务秘密不会因高亮教学提前显露。
- 色弱方案为有效格、无效格、悬停格和路径分别配置颜色加形状/纹理；低特效模式可关闭残影、水花和动态脉冲，但不能隐藏落点边界、危险提示或当前光标。

## 13. 边界与失败

- UI 锚点不存在：按 fallback 转为文本提示或延迟，绝不永久锁输入。
- 教程触发时系统已被玩家提前学会：检测完成事实，直接标记完成或显示简短提示。
- 存档只读：教程可本局展示，但不声称已永久保存；退出前提示。
- 设置值在设备不支持：回退安全默认并记录 `SETTINGS_UNSUPPORTED_VALUE`。
- 引导与剧情模态冲突：剧情优先，引导排队。
- 自动战斗教学在擂台中不触发，首章教学只在 PVE 上下文运行。
- 跳跃或踏水教学中能力被换下、落点失效或发生恢复：立即释放教程输入域，等待 26 恢复完成后重新评估；不得保持旧候选或自动确认新落点。
- 玩家跳过轻功教学后仍按正常权威规则行动；若不具备能力，显示正式系统的能力不足反馈，教程不得代填条件。

## 14. 配置校验

- tutorial_id、step_id 唯一；前置图无环。
- target_anchor 必须在 UI 锚点注册表存在或声明 fallback。
- advance_on 事件类型和 payload 字段合法。
- 所有 advance_on 事件均存在于 EventSchemaRegistry，且过滤字段与生产者 payload Schema 一致；禁止 DialogueFinished、ItemEquipped、CraftSucceeded、CombatEventObserved 等未注册别名。
- blocking 教程必须允许关闭/设置/必要辅助动作。
- 所有 message_key 存在；重看项拥有帮助页分类。
- 默认按键在所有支持布局上无非法冲突。
- 轻功四个 action_id 均有键盘与鼠标/UI 等价路径；教学步骤引用的 TraversalEvent 在 EventSchemaRegistry 中存在且 payload filter 合法。
- 色弱/高对比主题为有效、无效、悬停和路径状态提供非颜色区分；低特效配置不得关闭权威选择反馈。

## 15. 测试矩阵

- 引导候选稳定排序、事件去重、跳过、重看和中断恢复。
- 玩家提前完成动作、锚点缺失、切地图、断线和 UI 重建。
- 模态冲突与输入锁释放；任何异常后紧急关闭仍可用。
- 设置预览取消、提交、重置、非法范围、设备不支持和跨设备读取。
- settings_profile/tutorial_progress 唯一 owner、非 owner 写入拒绝、同一检查点与其他槽 1/5 section 合并不丢字段测试。
- 输入冲突、文本输入屏蔽、恢复默认和 UI 动态按键提示。
- 首次跳跃教学的打开选点、有效/无效格识别、光标移动、确认、取消、落点失效重校验和完成事实测试。
- 大量可见格、动态阻挡、隐藏格、spatial/world/profile 来源向量变化、不同分辨率和 Point SceneUI fallback 下，教程目标锚点与提示顺序仍正确测试。
- 首次踏水教学的进入、移动、离开、换下能力、断线恢复，以及 `WaterWalkEntered`、`WaterWalkExited` 事实测试。
- 跳过轻功/踏水教学不授予能力、不改变可达格、不创建 TraversalSession、不推进依赖权威事实的任务测试。
- 默认、色弱、高对比、低特效组合下轻功覆盖层关键状态仍可辨识测试。
- 新档完整十一段教学与逐段/全部跳过教学两条 E2E。

## 16. 验收标准

- 玩家可跳过全部非强制教学且主线不被卡住。
- 所有教学可在帮助页重看，不重复发奖励。
- UI 重建、切地图或重进后不会遗留输入锁。
- 设置预览可回滚，提交后按存档策略恢复。
- 玩家云偏好只从槽 1恢复，教程只从槽 5恢复，设备画质只从本地恢复且不会跨设备覆盖。
- settings_profile 与 tutorial_progress 写入均通过 SaveCoordinator，且不会覆盖共享槽中的其他系统 section。
- 键鼠路径均可完成首章关键操作。
- 首次跳跃与踏水教学均可跳过、可重看；完成只接受 26 的权威事实，教学状态无论如何变化都不能改变 LightnessTraversalProfile、TraversalSession 或角色位置。
- 轻功选点在默认、色弱和低特效设置下均能区分有效、无效、悬停、路径与取消状态。

## 17. 实施任务拆分

1. 冻结教程 Definition/Progress、语义锚点和设置 Schema。
2. 实现纯 Lua 条件、调度、状态机和迁移测试。
3. 实现应用用例、事件消费和幂等推进。
4. 建立遮罩、高亮、输入作用域和帮助页适配。
5. 接入十一段首章教程，其中首次跳跃和踏水步骤只消费 26 的权威事实并提供完整键鼠教学。
6. 实现设置预览、提交、输入绑定和设备能力映射。
7. 完成中断恢复、可访问性和 E2E 验收。
8. 为轻功选点覆盖层冻结色弱、高对比和低特效设置，验证任何显示偏好都不改变候选集与权威重校验。

## 18. 待决项

- Y3 是否提供可靠设备本地持久化接口需验证。
- UI 缩放、色弱与字幕的实际可用能力需结合最终 UI 框架确认。
- 教学短视频是否纳入首章素材范围待内容评审，默认使用图文演示。
