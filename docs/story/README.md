## 方向 3（现行）

**弱化户籍 / 失名 / 复籍；主轴为调查旧案、门派共谋、灭证与护送证人。**

- 核心命题：在人人想让证人闭嘴时，把人护到能把话说完，并承担说完的代价。
- 势力更名：无籍营 → **灰烟寨**；照册堂 → **同尘阁**。
- 开局钩子：伪匪灭口、夺旧案抄本与拓文——不是抢秋籍办户口。

详见 `00-叙事总纲.md`。
