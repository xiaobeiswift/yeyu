# 闻鹤生

| 项 | 内容 |
|---|---|
| 战斗 | 拳、反击控制 |
| 出身 | 留声馆抄录；归鹤台弃徒 |
| 信念 | 证据要完整，说法要可复核 |
| 恐惧 | 自己把活人痛苦写成好看故事 |
| 欲望 | 从旁观记录者变成敢为证词担责的人 |

## 声音支柱

1. 爱校正用词：「这是事实，那是推断。」
2. 冷一点，但不是无情。
3. 拓碑、抄录时话少。
4. 被质疑「冷血」时会卡壳。

## 方向 3

记录簿三栏的人肉说明书。他追的是**可对质的旧案**，不是户籍考古。

## 首章

沉钟院前入队；听痕与拓文；五选四替补出现。

## 好感

- 加：区分事实/煽动、保护证人完整陈述、不毁可能不利己的证据。
- 减：伪造、断章取义、为帅而瞒。
