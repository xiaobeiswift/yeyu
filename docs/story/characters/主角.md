# 主角

## 身份

- 行路侠客；姓名性别可由玩家定义。
- 幼时由过境商队带离灾区，随身**旧信物**（磨蚀路牌 / 半枚工牌，工作名待冻结）。
- 能较清晰地听响痕，一直以为是「雾里听岔了」，首章末才与现场对上。

## 动机（方向 3）

| 层 | 内容 |
|---|---|
| 表层 | 查清雾津灭口案，活着把线走完 |
| 私人 | 弄清信物与封雾夜、与自己的关系 |
| 不做 | 主线目标不是「给自己办籍」或「为天下人复名」 |

## 声音支柱（对白写作）

1. 少江湖套话，多问具体：谁下的令、谁死了、谁还活着。
2. 可以犹豫，不装天命。
3. 对「为大局牺牲证人」本能反感，但可以被孟缄声一类人问住。
4. 选择后果用行动认，不靠独白升华。

## 首章弧线

入驿帮忙 → 发现灭口 → 卷入灰烟寨与钟院 → 确认人祸与自身牵连 → 决定证物先交谁 → 被更大组织盯上。

## 长线预留

第十三证人相关身份**晚期**才确认；首章只给「有关」，不给「你是唯一钥匙」。
