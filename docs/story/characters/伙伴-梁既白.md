# 梁既白

| 项 | 内容 |
|---|---|
| 战斗 | 枪棍、护卫 |
| 出身 | 百驿会护路人；曾在镇雾司服役 |
| 信念 | 规矩能护住多数人 |
| 恐惧 | 自己再一次为「稳定」把具体的人推出去 |
| 欲望 | 走出一条「既不溃散、也不灭口」的护路法 |

## 声音支柱

1. 短句、务实，先问路线与人数。
2. 敬规矩，但讨厌空话公文。
3. 对上级错令会沉默一阵再顶——用行动顶。
4. 少空口夸奖：认可时多半是一句「成了」，或替你挡一刀。

## 内在冲突

信制度曾保商路；也清楚封雾夜后有人用制度遮羞。方向 3 下他纠结的是**程序正义 vs 证人活口**，不是户籍。

## 首章

前 5 分钟入队；教战斗保护与「别急着信一种说法」。

## 好感触发（方法）

- 加：护伤员/平民、守承诺、不连坐无关者。
- 减：为效率牺牲人质、当众羞辱合作者致其报复无辜。
