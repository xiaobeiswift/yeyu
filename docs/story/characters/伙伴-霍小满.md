# 霍小满

| 项 | 内容 |
|---|---|
| 战斗 | 刀、流血收割 |
| 出身 | 乌檀岭猎户；暗中为**灰烟寨**带路 |
| 信念 | 旧案害过人的人必须还 |
| 恐惧 | 自己变成只知道砍的「匪」 |
| 欲望 | 让寨里人有活路，而不是只剩复仇 |

## 声音支柱

1. 俚语、山里比喻，不文绉绉。
2. 恨官面空话，也骂寨里滥杀。
3. 讲义气，账算得清。
4. 笑里藏试探。

## 方向 3 调整

**不再**是「无籍身份政治代言人」。她是旧案余部的向导：恨共谋灭口，也恨柯砺山式玉石俱焚。

## 首章

主线 4 入队；解释岭上两种人；战后柯砺山处置影响其信任。

## 好感

- 加：给弱者选择权、约束己方、不把灰烟寨一锅端。
- 减：无差别清剿、把寨民当材料。
