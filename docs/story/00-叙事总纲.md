# 《雾州侠行》叙事总纲

> 文档状态：**方向 3 冻结稿 v0.2**
>
> 转向说明：废弃「失名 / 无籍 / 复籍」作为核心命题；主轴改为**调查旧案、门派共谋、灭证与护送证人**的传统武侠悬疑。
>
> 权威位置：`docs/story/`（本文件为叙事入口）

---

## 1. 一句话世界观

十八年前，雾州「封雾夜」被官府与五门定为地脉天灾；十八年后，一名行路侠客在雾津驿卷入一桩伪匪灭口案，顺线查到沉钟院与旧盟缄默——真相不是神功秘宝，而是一场被共同遮掩的人祸，以及至今仍在杀人灭证的共谋者。

## 2. 作品定位

| 项 | 内容 |
|---|---|
| 类型 | 低奇幻、重人情、带悬疑调查的单人武侠 RPG |
| 玩家身份 | 册上可有可无的行路人，**不是**天命救世主，也**不是**「要找回户口的人」 |
| 表层目标 | 查清灭口案、护送证人、揭开封雾夜人祸、对抗持续灭证 |
| 深层目标 | 决定真相应如何公开、由谁承担代价；江湖规矩是否允许揭师门与官署之丑 |
| 核心命题 | **侠，不只是替人报仇，更是在人人都想让证人闭嘴时，把人护到能把话说完的地方，并承担说完之后的代价。** |
| 情绪基调 | 清冷、克制、有人间烟火；悲剧来自护短与灭口，不靠滥杀堆气氛 |

## 3. 本方向明确不做的事

- **不做**以「名字被抹掉 = 社会性死亡 / 无户籍」为核心矛盾（易显现代户口感，且逻辑上不如直接灭口硬）。
- **不做**主角主线目标 = 给自己或万人复籍。
- **不做**「集齐宝物开秘境」「天选之人」「正邪终战」话术。
- **V1 不做**影响后续全章的大型分支树；局部选择只改对话、声望、资源与部分可回访内容。

## 4. 本方向明确要做的事

1. **层层翻案**：地方伪匪 → 岭上灭证 → 沉钟院旧场 → 五门护短 → 官署缄默 → 京畿总档。
2. **证人是活人**：十三名关键证人立场冲突；每找到一人，得到的是新事实、新矛盾、新责任，不是「进度点 +1」。
3. **灭证 vs 护证**：反派可以杀、可以毁卷、可以栽赃、可以断驿路；玩家侧是护送、取证、交叉印证。
4. **门派共谋**：五门并非全被官府胁迫，而是当年有人投票、有人执行、有人事后缄默；后辈与旧人分裂。
5. **响痕只是线索工具**：片段、可被执念扭曲，必须与活人证词、物证、地理痕迹互证，禁止一次回放破案。

## 5. 核心意象（保留，但换锚点）

| 意象 | 叙事功能（方向 3） |
|---|---|
| 雾 | 看不清责任归属；也能藏刀 |
| 路钟 / 沉钟 | 旧试验与旧命令的残响；关键剧情才鸣 |
| 驮铃 | 还在走的商路与活人世界 |
| 卷宗 / 碑拓 / 名牌 | **物证**，不是户口本；被抢被烧是因为能对上人 |
| 被铲的字 | 灭证痕迹（怕后人按碑找到人），不是「全民失籍」象征 |

「无名」在标题中的含义：**死者被写成天灾数字、无人敢具名指证**——不是「没户口」。

## 6. 文案口径

- NPC 先说自己的日子、买卖、师门恩怨，再说立场。
- 反派少讲抽象理念，多靠已经做过的灭口、栽赃、封院表现信念。
- 章节标题：八至十二字、前后分句；任务名：二至六字。
- 避免：「天选」「上古神功」「集齐四宝」「正邪终战」「复籍」「社会性死亡」等概括话术。
- 可用：「旧案」「灭口」「护短」「缄默」「证人」「伪匪」「共谋」「栽赃」。

## 7. 原创性边界

- 不使用《烟雨江湖》等参考作的角色名、门派名、地名、宝物、武学专名与案件过程。
- 只借鉴长篇武侠 RPG 的**节奏**：地方开局 → 跨区调查 → 伙伴加入 → 门派/官府介入 → 旧案翻转 → 阵营合流 → 终局抉择。
- 进入对白制作前，再做一次角色关系、标题、关键道具的相似度复核。

## 8. V1 首章必须讲清的四件事

1. 封雾夜的公开说法（天灾）与现场痕迹对不上。
2. 有人在**现在**仍为旧案杀人灭证。
3. 五门与官署的旧盟与沉钟院有关；主角与旧案有私人牵连（信物/旧姓痕迹），但首章不揭完身世。
4. 真相不是抢到手的宝物，而是**一群需要被保护、质疑和倾听的活人与物证**。

首章结束时，玩家应：喜欢五人队伍的雏形、理解至少两方「并非纯恶」的理由，并主动想知道「钟下到底下过什么令、我的信物为何在场」。
