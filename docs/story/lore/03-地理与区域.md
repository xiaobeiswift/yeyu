# 地理与区域

> 方向 3：地区功能服务**调查、灭证对抗、护送与门派戏**，不服务「复籍」。

---

## 1. V1 首章三地区

| 地区 / 子地点 | 功能 | 视觉与生活 | 主线意义 |
|---|---|---|---|
| **雾津驿** | 枢纽、教学、商店、委托 | 河埠、木栈、纸灯、驮队、潮雾 | 消息与车仗必经；伪匪灭口案在此开局；梁既白等在此登场 |
| **乌檀岭** | 探索、采集、分支、第一首领 | 黑木、陡坡、废亭、炭窑、雾狼 | 「山匪」不谋财，专取与旧案有关的人与物；灰烟寨线索 |
| **沉钟院** | 调查、机关、阵型战 | 半塌院墙、停摆水轮、覆苔铜钟 | 封雾夜地表试验场；十八年来有人阻止外人带走物证 |
| └ **地下钟窟** | 首章终局、两阶段首领 | 矿脉、悬钟、旧工棚、浸水名牌与残卷 | 确认人祸；主角信物痕迹首次对上；孟缄声决战 |

### 轻功叙事落点（与系统 26 对齐）

- 乌檀岭断栈道：**一处必经基础跳**（此前剧情保证 `JUMP_BASIC`）。
- 侧崖、残钟架：**两处可选高级跳**（线索/宝箱，不锁主线）。
- 地下水路：**可选踏水**（`WATER_WALK`）；主线另有机关放水路径，踏水不成为唯一门槛。

## 2. 后续扩展区域（纲要）

| 地区 | 核心矛盾 | 玩法倾向 |
|---|---|---|
| 白芦港 | 商路与黑市谁在转运灭口杀手与伪证 | 水路、追踪、船帮 |
| 砺霜城 | 军镇旧账与逃兵传说对上封雾夜 | 城防、军阵 |
| 栖霞府 | 名门与官署体面中心，护短最用力 | 交涉、推理、声望 |
| 归鹤台 | 拳理与史学，藏有被改过的江湖谱记 | 论武、文献比对 |
| 断潮坞 | 当年运铜料与钟件的水运枢纽 | 舟路、帮会 |
| 京畿司晦台 | 同尘阁总档与终局钟阵威胁 | 潜入、合流、终局选择 |

## 3. 地区气质一句

- **雾津驿**：人人赶路，无人想惹旧事。
- **乌檀岭**：林里有刀，刀后有两种恨。
- **沉钟院**：钟不鸣，人却怕它再鸣。
