# 历史年表

> 方向 3：公认说法 vs 隐藏真相。弱化删籍，强化**定调、毁证、灭口、护短**。

---

| 时间 | 事件 | 公认说法 | 隐藏真相 |
|---|---|---|---|
| 二十八年前 | 北关战乱，流民与商路压力涌入雾州 | 雾州收容、重开商路 | 官署强化路引与巡检，门派介入护商，权力与商路绑得更紧 |
| 二十二年前 | 「定路盟」成立（官署 + 五门 + 大商） | 合力剿匪、护送商旅 | 同时秘密研究息砂与古钟，欲以钟鸣「辨识潜伏、震慑匪患」 |
| 十八年前 | **封雾夜** | 地脉震动，百年雾灾 | 十二座路钟联动试验失控；官、商、门派均有人参与下令或执行 |
| 十七年前 | 沉钟院封闭 | 院中弟子殉难于天灾余波 | 幸存者被分散看管；不利物证封入钟窟；对外只留抚恤名册 |
| 十二年前 | **同尘阁**成形（无公开名号） | （无记载） | 由部分文吏、门派执事、商路主事构成，专责统一口径、销毁外流证据、必要时灭口 |
| 约五年前 | 旧案私探被断 | 「妄议天灾者自取其辱」 | 数名试图对照碑拓与抚恤名单的人死于「匪劫」或「急病」 |
| 三年前 | 乌檀岭「匪患」加剧 | 流民聚众为匪 | **灰烟寨**成形：旧案遗属与知情流亡者；一派要公开真相，一派要复仇；亦有外人借匪名灭口牟利 |
| 当下 | 雾津驿外车仗被劫 | 普通山匪抢掠 | 劫匪专取**旧案相关抄本、证人线索与拓文**，杀人灭口；主线由此开始 |

## 使用说明

- **首章玩家**只需吃到：当下灭口不像普通劫财 + 钟油等旧物 + 沉钟院有人在守不让进。
- **第二卷起**再展开五门投票与同尘阁建制。
- 年表数字为工作年，可在数值/年龄冻结时微调，但「十八年前封雾夜」为锚点。
