# 世界规则

> 隶属 `docs/story/` 叙事权威。方向 3：调查旧案 / 灭证护证。  
> **不设**「失名 = 社会性死亡」为世界支柱。

---

## 1. 雾与息砂

雾州地底富含灰白矿尘，民间称**息砂**。潮气重时逸散于低谷与旧矿，令人眩晕、咳嗽；武者运功不慎会加重不适。

息砂本身不是妖气，也不制造「全民失名」。它只做一件与本作悬疑相关的事：在大量内息、钟鸣或剧烈冲突下，把**片段式**的声音、动作与情绪留在金石表面，形成**响痕**。

## 2. 响痕（调查规则，四条必须遵守）

1. **只留片段**，不能像影像一样完整重放。
2. **会被聆听者的恐惧、执念和先入之见扭曲**，不能单独当绝对证据。
3. **大型铜钟**会放大响痕，也可能导致附近的人短暂耳鸣、失语、记忆错位——这是危险与戏剧手段，**不是**长期社会身份机制。
4. 主角比常人更易听清响痕，是因为**幼年经历过封雾夜现场**，不是血统神授。

**设计结论**：玩家不能靠一次「超能力回放」结案。每个结论都要由响痕 + 活人证词 + 文书物证 + 地理痕迹 + 利益关系互相印证。

## 3. 武学（叙事层）

武学仍是人的技艺：套路（拳/剑/刀/枪棍）+ 内功 + 轻功；绝招靠战斗中聚气。

- 不同门派运气与步点，可在响痕解读里当「技术指纹」（谁在场运过功）。
- **响痕技**不是独立法术树，而是极少数人以呼吸、步点、兵器震动与环境共鸣的技巧，首章仅作剧情/探索点缀。

数值与系统细节见 `docs/systems/04-武学系统.md`、`26-轻功探索与特殊通行.md`。

## 4. 缄默规矩（替代「失名秩序」）

封雾夜之后，参与善后的官署与五门之间形成不成文的**三不暗约**：

| 暗约 | 含义 | 玩家可见后果 |
|---|---|---|
| 不究 | 不公开追责当年决策者 | 旧案话题在城里被岔开、被劝酒压下 |
| 不录 | 不保留会指向人祸的正式记录 | 官方卷宗只有「天灾抚恤」套话；真东西在私藏与碑拓里 |
| 不问 | 江湖晚辈不追问师门旧事 | 好奇者被斥为妄议、被断荐书，硬查则惹刀

违者面临的不是「名字从天下消失」，而是很传统的江湖与官场手段：

- **栽赃**（安上匪通、私通外敌）
- **除名门墙**、断师徒与商路
- **灭口**（针对可能上堂的证人与持证之人）

> 一句话：刀负责让人闭嘴；伪证与统一口径负责让刀看起来正当。

## 5. 封雾夜（世界真相骨架，首章只揭一层）

**公开说法**：地脉震动引发百年雾灾，死伤与失踪者按天灾抚恤。

**隐藏真相（制作组知，玩家分层获得）**：

- 当年官、商、门派以「辨识潜伏者 / 安定商路」为名，对十二座路钟与息砂做联合试验。
- 试验失控，钟鸣与矿尘造成大规模伤亡；沉钟院是地表关键场之一。
- 事后定调天灾，销毁或封存不利记录，分散看管知情人；**灭证延续至今**。
- 《沉钟录》类档案记录的是**决策、命令链与伤亡估算**，不是神功秘籍。

## 6. 主角听痕与私人动机

- 主角身上有一枚**磨蚀的旧信物**（路牌/半枚名牌/商队信符，工作名可再定），能对上钟窟或旧卷中的痕迹。
- 首章末可确认：主角与封雾夜现场有关，**不能**立刻确认父母、血统或「唯一天命身份」。
- 主线欲望：**查清旧案与灭口链，弄清自己与当晚的关系**——不是去衙门办户口。

## 7. 与系统的边界

| 叙事概念 | 进入系统时 |
|---|---|
| 响痕交互 | 世界交互物 + 对话/调查节点；领域不存「超能力状态机」乱写 |
| 证人存活/失联 | 任务 flag、对话事实、世界 flag |
| 栽赃/声望变化 | 门派声望与局部 NPC 态度，不锁死主线通关 |
| 记录簿三栏 | 已确认事实 / 证人说法 / 待证疑点（见章节事实卡） |
