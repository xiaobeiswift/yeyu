# 第一卷 · 钟下无名

> 章目标识建议：`chapter_01_bell_below_no_name`  
> 「无名」= 死者被写成天灾数字、无人敢具名指证；**不是**没户口。

---

## 1. 目标时长

| 项 | 指标 |
|---|---|
| 主线核心 | 55–65 分钟 |
| 含 6 支线完整体验 | 70–85 分钟 |
| 地区 | 雾津驿、乌檀岭、沉钟院 / 地下钟窟 |
| 可用角色 | 主角 + 梁既白、苏见微、霍小满、闻鹤生（末段五选四） |
| 首领 | 柯砺山、孟缄声 |
| 任务 | 主线 9 步 + 支线 6 条 + 悬赏/委托循环入口 |

## 2. 本卷必须交付的体验

1. 打完一场「不像劫财」的灭口案，学会战斗与基础系统。
2. 明白灰烟寨不是脸谱山匪，柯砺山有真实伤痛与错误手段。
3. 在钟窟确认：**人祸 + 主角与现场有关 + 有人仍在灭证**。
4. 做一次局部选择（证物交给谁），主线仍汇入第二卷钩子。

## 3. 本卷禁止

- 复籍 / 办路引当主线高潮。
- 三套完全不同的长期主线。
- `WATER_WALK` 锁死主线；必经跳前必须已给 `JUMP_BASIC`。
- 永久不可逆失败锁死首章（主线 `NO_FAIL`）。

## 4. 教学锚点（分散，可跳过，跳过不给能力）

移动 → 交互 → 战斗与聚气 → 采集/装备 → 搜索 → 轻功基础跳 →（可选）踏水 → 阵型换位 → 制作入口 → 记录簿三栏。
