# 第一卷记录簿事实卡

> 记录簿三栏是本作叙事辨识度界面。  
> **已确认事实**须至少两个独立来源互证后才写入。  
> 方向 3：内容围绕旧案 / 灭证 / 人祸，不写复籍进度。

---

## 栏位定义

| 栏 | 规则 |
|---|---|
| 已确认事实 | 双源以上；玩家可当作可靠前提 |
| 证人说法 | 保留说话者、场合、利益；**不自动升格为事实** |
| 待证疑点 | 问句；随搜索/对话/战斗更新或关闭 |

## UI 文案注意

- 事实句短、可验证。  
- 说法句带主语。  
- 疑点必须是问句。  
- 禁止把单一响痕直接写成「已确认事实」。
