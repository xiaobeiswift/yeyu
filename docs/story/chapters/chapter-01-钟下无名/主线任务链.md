## 1. 夜投雾津

| 项 | 内容 |
|---|---|
| 接取 | `AUTO_EVENT` 开场 / 或驿丞 `MANUAL_NPC` |
| 阶段建议 | 入驿对话 → 选武器/初始套路 → 与梁既白会合 → 接「查近期匪患」 |
| 目标类型 | 对话、到达、（可选）商店/装备教学 |
| 队伍 | **梁既白**入队（约前 5 分钟） |
| 日志 | 「雾津驿要个帮手查匪。梁既白说：先别信路上任何一种说法。」 |
| 记录簿 | 疑点：匪患为何忽然盯上抄录车？ |

**叙事要点**：主角是行路人，可有自定姓名；**不要**用「查无旧籍不能住店」当卡点。住店/委托用常规江湖理由即可。

## 2. 驿道灭口

| 项 | 内容 |
|---|---|
| 接取 | 主线连锁 |
| 阶段 | 赶往事发栈道 → 战斗 → 检查现场 |
| 目标类型 | 到达、击败、搜索/调查 |
| 教学 | 双人战、普攻、聚气绝招 |
| 现场结论 | 银钱货物多在；**旧案抄本、证人名录残页、拓文**失踪；死者是抄录吏/护送者 |
| 日志 | 「这不像抢钱。像怕有人把旧事抄出来。」 |

**已确认事实（需双源）**：至少「只取文书类」+「死者身份与旧案抄录有关」。

## 3. 雾病与黑木

| 项 | 内容 |
|---|---|
| 阶段 | 追踪迹入岭 → 遇雾病伤员 → 苏见微出手 |
| 目标类型 | 到达、对话、采集（教学）、击败小战 |
| 队伍 | **苏见微**入队 |
| 关键物证 | 袭击者用的**钟油**（十八年前沉钟院一带制式，已停产） |
| 日志 | 「伤员喘得像淹在钟声里。苏见微说这油不该再出现在活人刀上。」 |

## 4. 岭上没有匪

| 项 | 内容 |
|---|---|
| 阶段 | 炭窑、废亭、被铲字的墓碑/石刻 → 基础轻功过断栈 |
| 目标类型 | 搜索、到达、轻功成功落地事实、对话 |
| 队伍 | **霍小满**以向导入队 |
| 教学 | 搜索；`JUMP_BASIC` 必经跳（此前剧情已授予） |
| 结论 | 所谓山匪两股人搅在一起：灰烟寨自保/夺证，与假冒匪名的灭口者 |
| 日志 | 「霍小满说：岭上不是没有匪，是匪字盖住了两种人。」 |

## 5. 夺证之人

| 项 | 内容 |
|---|---|
| 阶段 | 入寨交涉 → 失败 → 首领战 → 战后处置伤者 |
| 目标类型 | 对话选择、击败首领 |
| 首领 | **柯砺山**（见首领剧情） |
| 他的立场 | 官面与五门用「证据」整过人；与其再被收回去封存，不如自己掌握或毁掉，以免证人再被利用 |
| 玩家不可 | 首章招募他 |
| 战后 | 可选交官府 / 百驿会医治 / 交霍小满的人（影响好感与声望，不锁主线） |
| 日志 | 「抄本抢回来一截。柯砺山败了，可他说的话还在。」 |

## 6. 子夜旧钟

| 项 | 内容 |
|---|---|
| 阶段 | 解读残页 → 前往沉钟院 → 等子夜雾潮（首章唯一昼夜条件）→ 入内 |
| 目标类型 | 调查、到达、（可选）踏水探索支路、对话 |
| 队伍 | **闻鹤生**入队；首次出现五人池，战斗五选四 |
| 日志 | 「残页写：钟下旧令，子夜潮起可见。闻鹤生要拓，不要猜。」 |

## 7. 钟下遗证

| 项 | 内容 |
|---|---|
| 阶段 | 水轮、钟架、碑拓与听痕 → 记录簿教学强化 |
| 目标类型 | 机关/调查交互、到达、可选分队站位战 |
| 揭示 | 部分命令残片：非常规天灾；抚恤名册与现场名牌对不齐；**主角信物刻痕出现在旧名牌/工牌残件上** |
| 日志 | 「名牌不会说话。是人怕它们说话。」 |

## 8. 守院人

| 项 | 内容 |
|---|---|
| 阶段 | 孟缄声劝退 → 开战 → 两阶段 |
| 目标类型 | 击败首领（可含打断/机关目标） |
| 立场 | 守了十八年：官、门、寨、侠，谁拿走物证都会再杀人；宁可封死 |
| 战后 | 不简单处决；失聪/重伤，交出残页，可成为后续回访证人 |
| 日志 | 「他拦的不是我们。他拦的是下一场封雾。」 |

## 9. 证物交谁

| 项 | 内容 |
|---|---|
| 阶段 | 回雾津驿 → 三选一 → 结算与第二卷钩子 |
| 目标类型 | 对话选择、`choose_branch` |
| 选择 | 见 `关键选择与变量.md`：上呈镇雾司 / 托付百驿会 / 当众展示部分名牌拓文 |
| 共通结果 | **同尘阁开始追查主角**（尚未具名，以「有组织的追踪」表现） |
| 日志 | 「东西交出去了。路却比来时窄。」 |
