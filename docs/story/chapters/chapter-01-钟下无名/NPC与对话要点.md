## 3. 各 NPC 要点

### 驿丞

| 入口 | 说明 |
|---|---|
| 主线 1 | 匪患烦人、人手不够，雇行路人协查/护路（**不是**查无旧籍卡住房） |
| 主线 9 | 卷末三选一场地；中性陈述三方利弊 |
| 寒暄 | 驿务、雾、近来「匪」专挑文书车 |

**口径**：小人物被上峰与日子夹住；先生活后立场。

### 梁既白

- 主线 1 会合入队；支线「三步护行」。
- 短句、务实；不主动揭旧案；柯砺山战后会沉默一阵。
- 试探的是「你护不护具体的人」，不是「你有没有名字」。

### 苏见微

- 主线 3 救人入队；辨钟油；支线取脂。
- 医家口吻；对「必要牺牲」反感；钟窟前话少。

### 霍小满

- 主线 4 入队；解释岭上两种人（灰烟寨 / 假匪灭口）。
- **试探**：你是来清剿的，还是来问清楚的？（禁止「有名/无名」户口式试探）
- 对柯砺山：同根，不认同手段。

### 闻鹤生

- 主线 6 入队；拓文与三栏记录法。
- 「事实 / 推断 / 煽动」口头禅；孟缄声交残页时纠结记录还是保护。

### 柯砺山

- 主线 5：陈述后**无论选项都开战**（虚假选择）。
- 理由：证据回官门只会再变刀；要夺/毁关键抄本。
- 不讲户籍哲学；恨具体的夜与具体的人。

### 孟缄声

- 主线 8：怕物证被任一方利用再起杀；战后失聪，以交残页代替长篇。

## 4. 关键选择意图

### 任务 1 · 接委托（殊途同归入队）

| 选项向 | 意图 |
|---|---|
| 务实 | 谈报酬与路线 → 梁既白入局 |
| 挑战 | 质疑「为何只查不剿」→ 驿丞尴尬，梁既白仍来 |
| 观察 | 沉默听完 → 梁既白主动搭话 |

### 任务 5 · 柯砺山（虚假选择，必战）

| 选项向 | 意图 |
|---|---|
| 务实 | 劝先别毁证 → 失败，信息中等 |
| 挑战 | 驳其手段 → 交锋台词 |
| 观察 | 听完 → **信息最全**；霍小满好感微调 |

设计意图：有些绝望不是几句话能化解。

### 任务 8 · 孟缄声（必战，改信息量）

| 选项向 | 意图 |
|---|---|
| 务实 | 「我不是来利用死者的」→ 他不信 |
| 挑战 | 「你守住了什么」→ 触怒 |
| 观察 | 多听他的恐惧 → 背景最全 |

## 5. 对白纪律清单

- [ ] 真人会说的话；无「你也知道」互相灌设定  
- [ ] 先生活后立场  
- [ ] 反派少演讲，多已做之事  
- [ ] 无天选/神功/复籍话术  
- [ ] 伙伴声音支柱一致  
- [ ] 每节点有戏剧功能：揭示 / 关系 / 压力 / 后果
