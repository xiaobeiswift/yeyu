# 第一卷首领剧情

---

## 柯砺山（乌檀岭）

| 项 | 内容 |
|---|---|
| 身份 | 灰烟寨激进头领；外界称岭上匪首 |
| 战斗定位 | 护卫 + 后排点杀教学 |
| 剧情立场 | 旧案害过他的人；不信任任何官面与名门保管证据。手段：夺证、必要时毁证、对「会把人送官」的人刀硬 |
| 不是 | 单纯劫财土匪；也不是正确路线的嘴替 |
| 第一阶段 | 双盾卫护后排弩/刀；教集火与破卫 |
| 第二阶段 | 标记己方后排压力；逼换位或梁既白守护 |
| 战后 | 不可招募；伤者处置三选一；他指出的「证据会被再当刀用」 debatable，方法不可接受 |
| 回访 | 第二卷后视变量可闻其下落 |

**对白方向**：短句、恨具体的人与具体的夜，不演讲「户口哲学」。

## 孟缄声（地下钟窟）

| 项 | 内容 |
|---|---|
| 身份 | 沉钟院最后守院人 |
| 战斗定位 | 两阶段；召唤；可打断蓄力 |
| 剧情立场 | 守十八年：无论谁拿走完整物证，都会再开杀戒。他阻止玩家，是怕悲剧重演，不是称霸 |
| 第一阶段 | 三组「钟影」——互相冲突的旧命令残响具象 |
| 第二阶段 | 蓄力「归寂一鸣」；预警内打断或借场景削弱 |
| 战后 | 不处决流；重伤/失聪，交残页；**后续可回访证人** |
| 主题功能 | 让玩家第一次认真考虑：「公开」也有尸山 |

**对白方向**：疲惫、决绝，少反派笑。他怕的是「下一场封雾」，不是玩家等级。
