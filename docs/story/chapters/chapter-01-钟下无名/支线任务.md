# 第一卷支线任务

> 六条均**不阻塞主线**；可 miss（除与教学强绑定且已在主线重复教学的）。  
> 接取尽量挂主线进度窗，避免开局刷屏。

---

## 总表

| 支线 | 建议 quest_id | 教学 | 小故事（方向 3） |
|---|---|---|---|
| 雾里寻铃 | `quest_side_01_find_bell` | 搜索 | 替驿童找回驮铃；铃声线索指向灭口者离去方向 |
| 乌檀取脂 | `quest_side_02_black_resin` | 采集 | 为苏见微采黑木脂制定神药；顺带得知钟油民用来源 |
| 断轴重铆 | `quest_side_03_axle_rivet` | 制作 | 修好被袭车仗断轴；制作与驿路恢复发生关系 |
| 三步护行 | `quest_side_04_three_steps` | 阵型 | 梁既白教前后排保护伤员/抄录吏 |
| 石门后的碑 | `quest_side_05_stele_behind_door` | 隐藏地点 | 废窑后私祠：灰烟寨为旧案死者立的无官面碑 |
| 夜谈刀剑 | `quest_side_06_night_talk` | 伙伴好感 | 夜宿听谁讲「旧案该不该翻」；首次方法向好感反馈 |

## 1. 雾里寻铃

| 项 | 内容 |
|---|---|
| 接取窗 | 主线 2 前后；驿童 / 马夫 NPC |
| 步骤 | 对话接取 → 搜索 2–3 点 → 交还 |
| 叙事奖 | 小钱或消耗品；记录簿**疑点**更新（离去方向） |
| miss | 可；不影响主线战斗 |

## 2. 乌檀取脂

| 项 | 内容 |
|---|---|
| 接取窗 | 苏见微入队后 |
| 步骤 | 对话 → 采集点 → 交付苏见微 |
| 叙事奖 | 药品；钟油「民用/旧供」背景一句 |
| miss | 可 |

## 3. 断轴重铆

| 项 | 内容 |
|---|---|
| 接取窗 | 主线 2 完成后 |
| 步骤 | 接取 → 收集/购买铆件 → 制作交互 → 交付 |
| 叙事奖 | 驿路好感；制作解锁感 |
| miss | 可 |

## 4. 三步护行

| 项 | 内容 |
|---|---|
| 接取窗 | 梁既白在队 + 有伤员相关主线进度 |
| 步骤 | 对话教学 → 指定阵型战斗或演习 → 完成 |
| 叙事奖 | 梁既白好感；阵型熟练 |
| miss | 可（主线战斗仍可用默认阵型过） |

## 5. 石门后的碑

| 项 | 内容 |
|---|---|
| 接取窗 | 主线 4 探索中；可 `HIDDEN_UNTIL_REVEALED` |
| 步骤 | 发现隐藏交互 → 调查碑文 → 可选告知霍小满/闻鹤生 |
| 叙事奖 | 灰烟寨视角一条**证人说法**；小拓文道具 |
| miss | 可；不锁主线 |

## 6. 夜谈刀剑

| 项 | 内容 |
|---|---|
| 接取窗 | 至少两名伙伴在队；夜宿节点（主线 5 后或 6 前） |
| 步骤 | 选择听谁说完 → 可选简短表态（方法向，非善恶条） |
| 话题 | **该不该翻旧案、刀先落还是证先出**——禁止做成「名字意蕴」专题 |
| 叙事奖 | 对应伙伴好感；记录簿增加一句立场鲜明的**证人说法**（伙伴视角） |
| miss | 可 |

## 重复内容（非支线，入口叙事）

- **悬赏**（镇雾司）：清匪、缉拿，口径偏秩序。  
- **驿站委托**（百驿会）：护送、寻物、打听，口径偏民间网络。
