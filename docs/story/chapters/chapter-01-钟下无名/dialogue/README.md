## 写法约定

1. **先生活，后立场**；反派少演讲。  
2. 禁用：天选、神功、复籍、无籍户口戏。  
3. 可用：旧案、灭口、伪匪、护短、缄默、证人、物证。  
4. 表中 `text_key` 与现有对话图一一对应；标 **【扩】** 的句子待扩图后再挂 key。  
5. 玩家选项只写**意图标签 + 玩家可见短句**，不写内心独白长篇。
