# 开场视频 → 按任意键进入游戏 · 最终实现方案

## 链路
```
游戏启动 → mount OpeningCinematicShell
         → 真播 custom/Video/kaichang.mp4（你建的 video 控件）
         → 视频播完 / 按 ESC 跳过 → 定格 → 显示「按任意键进入游戏」
         → 玩家按任意键 → 隐藏开场 → mount 现有 BootMenuShell（开局菜单）
```

## 分工（关键）
| 谁 | 做什么 |
|---|---|
| 我（AI） | ① 用 `y3-ui-generator` 生成 OpeningCinematic 画板的**背景层 + 提示文本控件** → ② 写全部 Lua(状态机+展示层+接线) → ③ 用 y3editor MCP 热更/保存/生成节点树 → ④ 写离线测试 → ⑤ 更新文档 |
| 你（用户） | ① 在 Y3 编辑器里**手动加一个视频控件 type51**，命名 `video`，铺满屏（我生成完画板 JSON 热更进去后，你在编辑器打开 OpeningCinematic 加这个控件即可）→ ② 确认视频能播 |
| 原因 | `html_to_y3_ui.py` 的 TYPE_MAP 不含 Video(51)，第 419 行会跳过；视频控件只能编辑器手动建 |

## 实现步骤（共 6 步）

### 步骤 1：生成 OpeningCinematic 画板（AI，用 y3-ui-generator）
我生成一个 HTML 草图，含：
- `OpeningCinematic` 画板根（type 2 Layer，1920×1080，z-order 高于 GameHUD）
- `block` 全屏遮罩（type 7，纯黑，初始可见，用于视频播完前的黑底）
- `hint_text` 文本控件（type 3，居中偏下，大字号，文本"按任意键进入游戏"，**初始隐藏**）
- `skip_text` 文本控件（type 3，右上角，文本"按 ESC 跳过"，**初始隐藏**）

> **不含** video 控件——那个你手动加。
转换命令：
```bash
py -3 .y3maker/skills/y3-ui-generator/scripts/html_to_y3_ui.py \
  <临时html> maps/EntryMap/ui/OpeningCinematic.json \
  --panel-name OpeningCinematic --zorder 300
```
然后按 mcp-rules.mdc 的强制流程：`hotfix_ui_editor` → 等 3 秒 → `save_editor` → `gen_ui_tree.py` 生成 `ui_tree/OpeningCinematic_Tree.json` 供我查精确控件路径/UID。

### 步骤 2：你在编辑器加视频控件（你）
在 Y3 编辑器打开 OpeningCinematic 画板：
1. 添加视频控件（type 51），命名 `video`
2. 铺满屏 1920×1080，置于 block 之下层
3. **不在属性面板填 URL**（文档已确认：视频控件无 URL 字段，路径由运行时代码注入）
4. 保存

完成后告诉我，我会用 `get_ui_canvas`(helper MCP) 复核控件树，确认 `OpeningCinematic.video` 路径正确。

### 步骤 3：写 Lua（AI，全在 wzx/ 下，合规）

**新增 `wzx/config/content/opening/opening_cinematic_v1.lua`** —— 配置（路径/文案/开关/节拍）：
```lua
return {
  version = 1,
  video_enabled = true,
  video_paths = { 'custom/Video/kaichang.mp4', 'assets/video/kaichang.mp4' },
  video_comp_path = 'OpeningCinematic.video',
  hint_comp_path  = 'OpeningCinematic.hint_text',
  skip_comp_path  = 'OpeningCinematic.skip_text',
  block_comp_path = 'OpeningCinematic.block',
  panel_name      = 'OpeningCinematic',
  enter_prompt    = '按任意键进入游戏',
  skip_prompt     = '按 ESC 跳过动画',
  fallback_beats  = { {0.0,'雾'},{0.4,'州'},{0.8,'侠'},{1.2,'行'} }, -- 视频不可用时回退
}
```

**新增 `wzx/application/boot/opening_cinematic.lua`** —— 纯逻辑状态机（零 Y3 依赖，可离线测试，与 boot_flow.lua 同风格）：
- 状态：`IDLE → PLAYING → HOLDING → ENTERED`
- `bind()` / `start()` / `mark_video_end()` / `skip()` / `confirm_enter()` / `get_view()`
- 用 `wzx.domain.common.result` 的 Result 类型；状态用 weak-key 表隔离
- `get_view()` 返回 `{ phase, show_video, show_hint, hint_text, entered }`
- `ENTERED` 后不可回退

**新增 `wzx/presentation/y3/opening_cinematic_shell.lua`** —— Y3 展示层（与 boot_menu_shell.lua 同风格）：
- `mount(options)`：绑定画板/控件 → 读配置 →
  - 若 `video_enabled` 且 `video` 控件就绪：`GameAPI.play_ui_video_comp(player, video.handle, path, ...)` + 监听 `"界面-视频播放完成"` → `flow.mark_video_end()`
  - 否则：fallback 文案动画（按 fallback_beats 用 ltimer 逐字显示），日志 `[WZX][开场] 视频不可用，回退文案`
- HOLDING 态：隐藏 video 控件，显示 hint_text = "按任意键进入游戏"、skip_text 隐藏
- 键盘：`y3.game:event('键盘-按下', nil, cb)`（任意键）+ 单独 `ESC` 跳过
  - HOLDING + 任意键 → `flow.confirm_enter()` → 隐藏画板 → 调 `options.on_entered()`
  - PLAYING + ESC → `flow.skip()`（定格到 HOLDING）
- 全程 `pcall` 包裹 Y3 调用（与 common_tip_panel.lua 一致），失败降级不崩
- `unmount()`：移除 trigger、隐藏画板、reset 状态机
- 关键日志（对应文档成功标志）：`视频控件已找到`、`play_ui_video_comp OK`、`视频播完→定格`、`按任意键→进入`

**改 `wzx/bootstrap/dev_runtime.lua`**（3 处小改）：
1. `clear_list`（30-47 行）加 3 个模块名（热重载）：
   `'wzx.presentation.y3.opening_cinematic_shell'`、`'wzx.application.boot.opening_cinematic'`、`'wzx.config.content.opening.opening_cinematic_v1'`
2. 新增 `mount_opening_ui()`（仿 `mount_boot_ui` 结构）：mount OpeningCinematicShell，`on_entered` 里先 `unmount` 开场再 `Scheduler.schedule('boot', mount_boot_ui)`
3. 末尾（129 行）把 `Scheduler.schedule('boot', mount_boot_ui)` 改为 `Scheduler.schedule('opening', mount_opening_ui)` —— 链路变 `opening → boot → dialogue`

**不改** main.lua / 可重载的代码.lua（已正确）；**不改** y3_runtime.lua（release 暂不接，保持 foundation-only）。

## 降级与容错（视频 API 本工程未验证过，必须有）
| 情况 | 行为 |
|---|---|
| OpeningCinematic 画板找不到 | 跳过开场，**直接走 boot 链路**，游戏不卡 |
| 画板在但 video 控件缺失 | fallback 文案动画，仍能"按任意键进入" |
| play_ui_video_comp 调用失败/无画面 | fallback 文案动画，日志提示查路径 |
| `"界面-视频播放完成"` 不触发 | ESC 跳过兜底（始终可用） |
| 任意键事件无响应 | ESC 硬兜底 |

任何降级都保证"能进入开局菜单"，不卡玩家。
